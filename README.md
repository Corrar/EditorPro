# EditorPro

Editor de vídeo com IA: descreva como quer o vídeo, envie o material e um vídeo-exemplo,
e a IA edita ao vivo — você acompanha a timeline e o preview mudando e corrige pelo chat.

- App: `web/` (Next.js 14). `cd web && npm install && npm run dev`.
- IA: copie `web/.env.example` para `web/.env.local` e coloque sua `ANTHROPIC_API_KEY`
  (https://console.anthropic.com/). Sem chave roda em modo demo.
- Design: `docs/superpowers/specs/2026-11-18-editorpro-design.md`.
